# Braumeister · Vom Malz zum Bier

Lern-App zum Bierbrauen in fünf Stationen: Rohstoffe, Maischen, Würze kochen und kühlen, Gärung, Reifung. Am Schluss gibt es eine Verkostung (Soll und Ist), Punkte pro Station und Verbesserungstipps.

## Aufbau

- `index.html` – die ganze App in einer Datei (HTML, CSS, JavaScript). Kein Build-Schritt nötig.
- Schriften kommen von Google Fonts. Ohne Internet fallen sie auf Systemschriften zurück.

Lokal einfach `index.html` im Browser öffnen.

## Veröffentlichen mit GitHub Pages

Settings → Pages → Source «Deploy from a branch», Branch `main`, Ordner `/ (root)`, Save. Danach ist die App unter `https://alexanderweng-prog.github.io/bierbrauen/` erreichbar.
